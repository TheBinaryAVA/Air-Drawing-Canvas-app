# 🎨 Neon Air Canvas

An interactive, browser-based "air drawing" application that uses your webcam and machine learning to let you paint on a dark canvas using hand gestures. No extra hardware or apps required—just your browser and your hands!

## 🚀 Features

* **Finger Tracking:** Draws a glowing neon trail following your index finger.
* **Gesture Controls:**
    * ☝️ **One Finger (Index Up):** Draw on the canvas.
    * 🖐️ **Open Palm:** Instantly clear/erase the canvas.
    * ✊ **Closed Fist:** Pause drawing (move your hand without leaving a trail).
* **Customization:** Built-in color picker and brush thickness slider to change your neon glow style in real-time.
* **Mirrored Display:** The webcam and canvas are horizontally flipped so it behaves like a natural mirror.

## 🛠️ Built With

* **HTML5 Canvas** - For rendering the glowing neon lines.
* **MediaPipe Hands** - For high-fidelity, real-time hand landmark tracking.
* **MediaPipe Camera Utils** - For managing the webcam video stream feed.
